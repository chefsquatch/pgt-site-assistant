# Precision Guesswork Technologies — Overview

Precision Guesswork Technologies (PGT) is an independent software studio. Its
core focus is **AI reliability**: making AI-assisted development produce accurate
output instead of drift, hallucination, and code nobody asked for.

The one-line positioning: **"We make AI-assisted development reliable."**

Teams using Claude and other AI to write code hit real problems — the AI drifts
off the spec mid-task, confidently invents APIs that don't exist, or produces
changes they didn't ask for, even when specs and guardrails are in place. PGT
finds where those failures actually come from and builds a disciplined process
that delivers accurate output without the constant rewrites.

PGT is run by its founder, **Les Fleming**. It is a small, hands-on studio, not
an agency or a staffing shop. The way to engage is by email, and the founder
works async and text-first — messages and results, not meetings.

Guiding principles PGT states publicly:
- **Local-first.** Software that works offline where it can.
- **Privacy-first.** Data stays on the device / stays yours where possible.
- **Nothing ships until it's right.**

PGT is a Michigan LLC (Precision Guesswork Technologies LLC). The website is
precisionguessworktech.com.
