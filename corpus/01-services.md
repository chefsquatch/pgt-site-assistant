# Services — What PGT Does

## AI Reliability — Fixing Drift & Hallucination (the spearhead)
This is PGT's flagship service. When an AI coding workflow produces output you
didn't ask for, forgets the spec mid-task, or confidently invents APIs, PGT
audits where the failures actually originate — prompts, context management,
process, or tooling — and rebuilds the workflow into one that ships accurate code
the first time. The approach is **diagnosis first, then a disciplined process the
team keeps.** The deliverable is not a one-off fix; it's a workflow the team can
run on its own afterward.

## AI Integration
Claude API builds, RAG (retrieval-augmented generation) systems, and tool use —
production integrations, not demos. PGT has live, working proof of this on the
site (the Claude Chat Demo and the Document Q&A / RAG demo). If someone needs an
AI feature built into their product reliably, this is the service.

## Custom App Development
Mobile and web apps built end-to-end — from a real human problem to a shipped
product. Full builds, not mockups.

## Local-First & Privacy
Software that works offline and keeps data on the device. Offered as both
consulting and full builds. The principle: your data stays yours.

## MVP & Prototype Builds
A working product in weeks, not quarters — scoped tight, built right, ready to
put in front of users. For founders and teams who need something real to test.

---

Note on what PGT does NOT list on its public services page: it does not advertise
fixed-price packages, hourly rates, retainers, or specific turnaround guarantees.
Engagements are scoped individually by the founder. If a visitor asks for a price
or a timeline, the honest answer is that Les scopes each engagement to the actual
problem — the corpus does not contain a rate card.
