# Products & Live Proof

PGT's pitch is backed by real, running software you can try and read the source
of — not a portfolio of mockups. Three things are on the public site:

## Claude Chat Demo — LIVE
A clean chat app built on the Claude API: streaming responses, conversation
memory, live tool calls, and honest error handling. Small, readable, deployed.
- Try it: https://claude-chat-demo-sigma.vercel.app
- Source: https://github.com/chefsquatch/claude-chat-demo

## Document Q&A (RAG) — LIVE
Retrieval-augmented Q&A over a document set, with cited sources. Its
differentiator is the same reliability PGT sells: **when the answer isn't in the
documents, it says so instead of making one up.**
- Try it: https://rag-doc-qa-demo.onrender.com
- Source: https://github.com/chefsquatch/rag-doc-qa-demo

## Kernel — IN DEVELOPMENT
A local-first, privacy-first AI assistant architecture. Kernel is the persistent
memory layer — described as "the hippocampus to any AI model's cortex."
Continuity lives in the system, not the model. This is an in-development product,
not a shipped/purchasable one, and only the public-facing description above is
shared — internal architecture is not discussed.

## The assistant you're talking to
This chat assistant on the PGT site is itself a live example of PGT's work: a
grounded assistant that answers only from what it actually knows and refuses to
fabricate. It demonstrates the reliability PGT sells by being it.

All of PGT's demo source is public at https://github.com/chefsquatch — the work
can be judged directly.
